# BOOKSCAN — JAKU

iPhone Safariで本を一定間隔で撮影するWebカメラです。

1. 公開ページをSafariで開き、「撮影開始」を押してカメラを許可します。
2. 「1枚だけ撮る」で試し、左下の写真から「保存 · JPEG」または共有シートで書き出します。
3. 間隔・保存方向・開始待ち・枚数を設定して連続撮影できます。

撮影中は画面を開いたままにしてください。マイク・音声は使いません。写真は各端末のブラウザ内に保存され、アプリからサーバーへ送信しません。写真を残すときは個別に書き出してください。インターネット接続が必要です。

このリポジトリは静的配布ファイルです。mainブランチのルートからGitHub Pagesで公開します。変更後のファイルをmainへpushすると再配置されます。第三者ライブラリ・参考UIの出典とライセンスは [credits.html](./credits.html) を参照してください。
