BOOKSCAN

JAKU · UI study / v0.2

  • Brand mark: JAKU. User-owned vector logo, used without altering the path.
  • Camera core: CamDesk / Michael Schwartz, MIT. License.
  • Animation: GSAP 3.13.0, Copyright 2025 GreenSock. Bundled official npm distribution, original notice retained. Standard no-charge license.
  • Shiny button border: adapted from Ryan Mulligan — Shiny call-to-action button. Changes: JAKU colors, slower motion, rectangular bevel, reduced-motion support; no hover dependency.
  • Visual references: Cadrage Director's Viewfinder (camera hierarchy); Codrops / Manoela Ilic — Morphing Buttons (settings reveal concept); Basile Bong — Segmented Control (selection-control reference). Their application code/assets are not bundled.
  • Typography: Montserrat / Noto Sans JP via Google Fonts, SIL Open Font License. System fonts remain available if fonts cannot load.
  • The book in mock mode is a synthetic canvas illustration, not a camera photograph.
